# University Event Management - Java MVC

This is a simple Java MVC project for managing university events.

## Features
- Add event
- Search event by ID
- Update event venue
- Display all events

## Project Structure
src/com/university/
- Main.java
- model/Event.java
- view/EventView.java
- controller/EventController.java

## Branches
- main
- feature/add-event
- feature/search-event
- feature/update-event
